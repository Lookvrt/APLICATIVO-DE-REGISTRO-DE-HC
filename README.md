
# Sistema de registros de Historias Clinicas

Aplicativo desarrollado 100% en netbeans con interfaces de java swing y almacenamiento de datos en binarios (.bin)


## 🔄️ Lo que se hizo

- Estructuras como `ArrayList, Lista enlazadas, Arboles binarios` para el almacenamineto de objetos en java.
- Algoritmo de busquedas para optimizar ratios de busqueda en los registros.
- Persistencia de datos 100% manejada en archivos binarios de java.
